## Вывод по нише

Свободен **не метод, а измерительный инструмент.**

Никто не делает именно «одинаковая история + один вызов, меняем только правдивый результат →
должно ли смениться действие». Соседние работы стирят *звать ли* инструмент, *приоритет*
спанов в иерархии инструкций, или следование формат-инструкциям в один ход.

**Отвергнутая рамка:** «как инструкция из промпта доходит до выбора действия» — ниша занята
плотно (2410.14516 + 2410.12877 делают ровно probe + интервенцию для instruction following).

### Механистический вопрос «почему явный текст не срабатывает» — сделан в single-turn

**[Do LLMs "know" internally when they follow instructions?, 2410.14516](https://arxiv.org/html/2410.14516v1)**
— прочитано (сводка). Находят внутреннюю размерность следования инструкциям, ставят probe,
вмешиваются в активации, следование растёт. **Single-turn, без агента и инструментов.**
Их вывод: сигнал переносится между задачами, но **не** между типами инструкций;
сильнее всего влияет формулировка.
→ *Прочесть полностью, чтобы точно отстроить дельту.*

### Иерархия инструкций и приоритет tool-output

**[V-Steer: Steering Instruction Hierarchies at Inference Time, 2607.26228](https://arxiv.org/html/2607.26228v1)**
— прочитано (сводка). Value-cache editing: находят головы, где низкоприоритетные спаны
доминируют над привилегированными, и правят value-векторы на prefill.
Бенчмарк IHEval включает tool outputs как нижний тир иерархии (system > user > history > tool).
Single-step конфликты спанов, не многошаговые эпизоды.
→ *Прочесть полностью.*

### TACT — прочитано (HTML, 2026-10-19)

[TACT: Mitigating Overthinking and Overacting in Coding Agents via Activation Steering,
2605.05980](https://arxiv.org/html/2605.05980) (Sui et al., 7 мая 2026, «work in progress»).
Прочитаны первые ~100k символов HTML (метод, гиперпараметры, абляции); хвост — нет.

- **Метки:** шаги траекторий coding-агента размечает LLM-судья (GPT-5.4, сверка с Claude
  Opus 4.6 и др., κ = 0.78 с людьми) на overthinking (OT), overacting (OA), calibrated (CAL).
- **Активации:** токен `</think>` каждого шага, все слои; вмешательство — на top-10 слоях
  (из 64) по per-problem AUC оси OT-vs-CAL на Axis-val.
- **Оси:** per-problem balanced mean difference, нормировка; OA ортогонализуется к OT
  (Грам–Шмидт).
- **Вмешательство:** проекция `p = (h − μ_CAL)·v̂`, полоса `τ = k·σ_CAL`; Cap — обрезка до
  полосы, Add — постоянный сдвиг, Gate — `h ← h − λ·excess·v̂` вне полосы. Выбрано k = 2,
  λ = 0.5 (Gate).
- **Результат (заявлен):** +5.8 п.п. resolve rate (Qwen3.5-27B), +4.8 (Gemma-4-26B), шагов
  до решения до −26% (SWE-bench Verified, Terminal-Bench 2.0, CLAW-Eval).

**Наша адаптация** (`methods.tact`, `pipeline._fit_tact`): только ось OA (решение без
рассуждения — оси OT нет, ортогонализовать не к чему); метки — правильность решения базы
по правилам среды, а не судья; точка — `action_point` (последний токен промпта, у Qwen3
без рассуждения — сразу после `</think>`); top-K = 15% слоёв по AUC на val; k = 2, λ на val.
Это **адаптация**, не воспроизведение, — так и называть в тексте.

**Отличие от нас по вопросу:** TACT борется с дрейфом длинной траектории coding-агента
(общее качество), мы меряем реакцию на **смысл конкретного ответа** в парном протоколе с
инвариантными контролями. Их overacting («вызовы, игнорирующие наблюдения») пересекается
с нашим целевым сбоем — заявлять первенство в «steering против игнорирования наблюдений»
нельзя; наше — парный причинный протокол и сравнение с явным состоянием/LoRA.
